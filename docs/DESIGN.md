# CineQuip 設計ドキュメント

Issue [#1](https://github.com/onigiri-masashi/CineQuip/issues/1) の要件に基づく MVP の設計。

## アーキテクチャ方針

**完全クライアントサイド処理。** 画像はサーバーへアップロードせず、すべてブラウザ内で加工する。

- サーバー・DB・ストレージが不要なため、Cloudflare Workers（Static Assets, 無料枠）だけで運用でき、ランニングコストがかからない
- 画像が外部に送信されないためプライバシー面でも安全

## 画面構成

単一ページの SPA。

```
┌──────────────────────────────┐
│ ヘッダー（ロゴ・キャッチコピー）│
├──────────────────────────────┤
│ 画像入力エリア（D&D / 選択）    │
│  → 入力後はプレビューに切替     │
│     ・フィルター適用プレビュー   │
│     ・字幕オーバーレイ          │
├──────────────────────────────┤
│ フィルター選択（サムネイル一覧） │
│ 字幕変更ボタン / 取消 / 保存    │
└──────────────────────────────┘
```

## 主要モジュール

| モジュール | 役割 |
|---|---|
| `components/ImageDropzone` | D&D / ファイル選択、最小サイズ検証 |
| `components/Preview` | フィルター + 字幕を重ねたプレビュー表示 |
| `components/FilterSelector` | フィルターのサムネイル選択 UI |
| `lib/filters.ts` | フィルター定義（CSS filter 文字列 + オーバーレイパラメータ） |
| `lib/export.ts` | Canvas 2D でフィルター + 字幕を焼き込んで PNG 生成 |
| `src/data/subtitles.json` | 字幕候補（管理者はこのファイルを編集するだけ） |

## フィルターの実現方法

プレビューは CSS で、保存は Canvas で同じパラメータを適用する。

- 色調: `filter: sepia() contrast() saturate() hue-rotate() ...`（CSS / `ctx.filter` 共通）
- ビネット: 放射状グラデーションのオーバーレイ
- フィルムグレイン: SVG ノイズ（プレビュー）/ ランダムノイズ描画（Canvas）

フィルターは 8 種類（8mmフィルム / モノクロ・ノワール / SF / 戦争映画 / ミニシアター / ウェスタン / ホラー / テクニカラー）。

## 字幕

- 画像入力時に `subtitles.json` からランダムに 1 件選択して表示
- 「字幕を変える」ボタンで再抽選
- 白文字・1 行固定・映画字幕調の日本語フォント（Google Fonts の明朝体）
- 画像取消で字幕・フィルターとも初期化

## 制約・検証

- 画像は 1 枚のみ。2 枚目を入れると置き換えではなくエラーにはせず置換する
- 最小サイズ未満（短辺 360px 未満を目安、実装時に確定）の画像は拒否しエラーメッセージを表示

## デプロイ

- wrangler + GitHub Actions で main への push 時に Cloudflare へ自動デプロイ
- 必要なシークレット: `CLOUDFLARE_API_TOKEN`（リポジトリシークレットに登録）
